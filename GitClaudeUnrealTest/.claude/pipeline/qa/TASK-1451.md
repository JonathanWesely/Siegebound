# C. THE `SetUserFocus` TRAP — THE POLL CANNOT READ A NON-FAILURE AS A FAILURE

2. **The log line precedes the call** and reports the button this function **chose**, which Slate cannot falsify. The reasoning is recorded in-source at `.cpp:441-446`, where it will survive the next edit.
