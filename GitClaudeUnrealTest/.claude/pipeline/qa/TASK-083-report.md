## Findings

- [WARN] refine_trellis_glb.py:290-292 — `apply_world_transform` is applied per imported object, but multi-user mesh datablocks (instanced meshes in a GLB) would be transformed once per user with different matrices → corrupted geometry. TRELLIS pilot output and the blockout smoke donors are single-mesh, so unreachable today. Fix (one line, any later hardening pass): `if obj.data.users > 1: obj.data = obj.data.copy()` before the transform.
- [WARN] refine_trellis_glb.py:485-491 + 679-712 — native-mode texture save relies on `filepath_raw` + `file_format="PNG"` + `Image.save()` on IMPORTED/PACKED (WebP) images. That pattern is proven for generated images (all bake-path outputs — fine), but Blender has historically honored `file_format` unreliably for file-backed/packed images (risk: WebP bytes under a `.png` name, or a save error). Native mode is the escape hatch, not the pilot default, so WARN not BLOCKER. Verify at first native-mode use (check PNG magic bytes); safer fix = pixel-copy into a fresh generated image (the `pack_orm` pattern) or `save_render`.
- [WARN] refine_trellis_glb.py:766-769 / handoff flag 4 — "slot 0 `TeamRegion` exists regardless" assumes Blender's FBX exporter retains a material slot referenced by ZERO polygons. Slot creation/order in code is correct (clear → append TeamRegion → append PBR; every polygon's `material_index` set explicitly), but empty-slot survival through export is asserted, not proven. TASK-084 smoke MUST assert the exported smoke FBX carries exactly 2 materials in order [TeamRegion, <CardID>PBR] (see carry-forwards). If the exporter prunes the empty slot, the slot-0 recolor contract breaks silently on a zero-face selector.
- [WARN] refine_trellis_glb.py:137-142 — `OutputGuard` roots derive from unvalidated `card_id` (`CACHE_ROOT / card_id`). With the repo manifest this is safe (card-id must match a manifest key: Footman/Archer/Castle, checked before any path use), but a custom `--manifest` with a key containing path separators / `..` would relocate the allowed root outside Tools/ArtPipeline (the CardArt hard-fail still holds). Defense-in-depth: reject card-ids that are not a single normal path component (`len(Path(card_id).parts) == 1 and card_id not in ('.','..')`).
- [NIT] refine_trellis_glb.py:845-859 / handoff flag 1 — the handoff says "one arg beyond the contract's four" (use_triangles), but the export also sets `use_selection=True`, `object_types={'MESH'}`, `apply_scale_options='FBX_SCALE_NONE'`, `use_mesh_modifiers=True`, `bake_anim=False`, `add_leaf_bones=False`, `path_mode='STRIP'`. - [NIT] refine_trellis_glb.py:1043-1057 — in non-smoke runs the shipping texture PNGs are written to `Content/RawAssets/Textures/<CardID>/` BEFORE slots/UCX/FBX export; a late failure leaves orphan PNGs with no report and the old FBX untouched.
