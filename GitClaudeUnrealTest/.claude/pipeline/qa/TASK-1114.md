## 2. THE BLOCKER

### 🚨 BLOCKER-1 — `SiegeGraphicsSettingsSubsystem.cpp:485` — `AutoDetectQuality()` persists an unconfirmed video mode, bypassing the `GFX-§4` guard entirely

**The trace, completed.** `AutoDetectQuality()` calls `Settings->ApplyHardwareBenchmarkResults()` (`:485`). Its complete engine body is **`GameUserSettings.cpp:1132-1143`**:

```cpp

{
	// Apply the new settings and save them
	Scalability::SetQualityLevels(ScalabilityQuality);          // :1135

	if (bEnableScalabilitySettings)
	{
		Scalability::SaveState(GGameUserSettingsIni);            // :1139  ← the author's trace stops here
	}

	SaveSettings();                                              // :1142  ← THIS
}
```

`UGameUserSettings::SaveSettings()` (`:672-698`) ends in `SaveConfig(CPF_Config, *GGameUserSettingsIni)` (`:683`), which writes **every** `UPROPERTY(config)` on the class — including `ResolutionSizeX` (`GameUserSettings.h:465`), `ResolutionSizeY`, `FullscreenMode` (`:500`) and `LastConfirmedFullscreenMode` (`:504`).

**Therefore:** stage a resolution → `ApplyVideoModeProvisional()` → the 10-second countdown is live → the player presses **Auto-Detect** → the unconfirmed `ResolutionSizeX/Y` + `FullscreenMode` are written to `GameUserSettings.ini`. The facade's guard is never consulted: `RequestSaveSettings()` (`:1098`) is not on this path, `SaveSettingsCallCount` does not move, `RefusedSaveWhileVideoModePendingCount` does not move, and the `Log` line that would have explained it is never emitted. This is **exactly** the failure the author correctly identified in F-A — *"the lockout arriving through a control that is not the resolution control"* — arriving through the button next to the sliders instead of through the sliders.

**Why the suite cannot see it:** `AutoDetectQuality()` returns early under automation suppression (`:454-460`), so no test reaches the benchmark; and even if one did, the save happens inside the engine, not at a counted facade call site. The defect is where the reading stopped. Both cite the range **`:1132-1140`**; the body ends at `:1143`.
