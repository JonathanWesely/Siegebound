## §3. THE FIVE DESIGN CHOICES, ADJUDICATED

### 1. Interface over delegate — ⚖️ **SOUND. UPHELD.**
The argument holds on inspection. `NavTargetStack` is `TArray<TWeakObjectPtr<UUserWidget>>` (`.h:599-600`);
a stored delegate would force it into a `USTRUCT` array carrying a `FScriptDelegate` `UPROPERTY`, which
rewrites `TASK-1406`'s weak-pointer contract and every lambda that reads it — a large, shipped-code-touching
change to buy something the interface buys for free. The interface adds **no member** and touches **no line**
of that stack (confirmed: the stack's declaration and all its uses are byte-unchanged in this diff). It
reaches Blueprints via `Blueprintable` + `BlueprintNativeEvent`, which is the same reason the registration
API is `BlueprintCallable`. The `UINTERFACE`/`I…` pair shape matches the project's own seven existing
interface headers (`HealthBarProvider.h:53`, `TeamId.h:25`, `LadderClimber.h:134`, four `Variant_*`) —
`GENERATED_BODY()` on both classes, `MinimalAPI`. This is the first **`Blueprintable`** one, correctly so.
⛔ I did **not** independently re-read `SequencerAnimationOverride.h`; the in-project precedent is stronger
evidence and it is seven-for-seven.
