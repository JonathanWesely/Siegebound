## Spells & Set III (M5)
Added 2026-07-08 (TASK-097..109; GDD §3.5/§3.11/§4 Set III/§7). Spells have NO actor blueprints — they resolve through code (see resolver). Crystal Tower is a normal building card (existing `BP_Building_<CardID>` / `SM_<CardID>` laws apply: `BP_Building_CrystalTower`, `SM_CrystalTower`; card art `T_CardArt_<CardID>` law applies to all 6 new CardIDs).
- **Set III CardIDs (row names, character-for-character):** `Fireball`, `FrostNova`, `Lightning`, `BattleCry`, `Pickpocket`, `CrystalTower`.
- **Spell resolver:** `USpellLibrary` (UBlueprintFunctionLibrary) in `Source/GitClaudeUnrealTest/Siegebound/SpellLibrary.h/.cpp` — the ONE home for spell resolution, shared by `ASiegePlayerController` (targeting mode) and `ASiegeBotController` (M5 bot rules). Entry point pinned: `static bool USpellLibrary::ResolveSpell(UWorld* World, FName CardID, const FCardRow& Row, ETeamId CasterTeam, const FVector& TargetPoint)`. Null-safe everywhere; no friendly fire (§3.0).
- **FCardRow M5 columns (typed one-per-concept, sparse; registry continues the M4 list):**
  - `SpellEffect` (`ESpellEffect` enum, `None`) — dispatch token: `None` / `AoEDamage` (Fireball) / `Freeze` (FrostNova) / `TopTargetsDamage` (Lightning) / `AllyBuff` (BattleCry) / `GoldSteal` (Pickpocket). Declared in CardRow.h. CSV cells use the enum value names.
  - `EffectDuration` (float, 0) — timed-effect seconds (FrostNova 4, BattleCry 8).
  - `MaxTargets` (int32, 0) — top-N target count (Lightning 3).
  - `GoldSteal` (int32, 0) — gold stolen, capped at what the victim has (Pickpocket 10).
  - `ChainTargets` (int32, 0) — Chain keyword arrives as its typed column per the M4 deferral note: total targets hit per attack (CrystalTower 3).
  - `ChainFalloff` (int32, 0) — flat damage reduction per bounce (CrystalTower 5 ⇒ 15/10/5 with Dmg 15).
  - Spells REUSE `Damage` (Fireball 100, Lightning 200) and `AoERadius` (Fireball 300, FrostNova 350, Lightning 400, BattleCry 400) — no duplicate radius/damage columns.
- **Mechanic rules (UPROPERTY defaults with GDD § comments, NOT CSV — M2/M4 precedent, e.g. Rally/Charge magnitudes):** BattleCry magnitudes (+50% attack speed, +25% move speed), `ChainBounceRadius` = 350 (bounce search radius from the previous target — GDD doesn't specify; manager-defined), freeze non-stacking refresh rule.
- **Targeting mode (§3.5/§7):** spells target ANYWHERE on the map (no half restriction); the ground reticle is TRACE-projected onto whatever surface is under the cursor (terrain-ready for M4.5 hills — LAW, not a follow-up); LMB confirms (gold deducted at confirm — card-leaves-hand-at-CONFIRM law), RMB/Esc cancels free. **Exception (manager ruling):** `GoldSteal` spells resolve INSTANTLY on play (no reticle for a global effect — recorded deviation from §3.5; CardType stays Spell).
- **Spell VFX (code contract):** every spell resolve spawns `/Game/VFX/NS_Spell_<CardID>` (Niagara, Content/VFX/), soft path COMPOSED from the CardID (mirrors the BP soft-class-path law), null-safe: missing system ⇒ log once, resolve anyway. Crystal Tower's chain visual is `/Game/VFX/NS_ChainZap`. Donor-duplicate authoring from Variant_Combat Niagara systems is acceptable at M5 (template-donor rule); §6 one-frame readability bar.
- **Targeting reticle material:** `M_SpellReticle` (Content/Materials/, DeferredDecal domain — M_CenterlineStripe recipe), soft-referenced by the targeting-mode code, null-safe (missing ⇒ no visual, targeting still works, log once).
