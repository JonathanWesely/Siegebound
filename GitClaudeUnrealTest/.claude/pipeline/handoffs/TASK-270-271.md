## MCP gotchas learned (save the next session time)
- `Game|ConstructObjectfromClass` output is generic Object until its `Class` pin is a literal path — then it retypes; connect Set<Var>/SetText/SetFontSize directly, no cast.
- AutoWrapText on a **TextBlock** = `Class|TextLayoutWidget|SetAutoWrapText` (a VariableSet, pins `[AutoWrapText(bool), self]` — **bind by keyword**). `Appearance|SetAutoWrapText` is the **RichTextBlock** overload and will not connect to a TextBlock.
- Member-var node ids **strip underscores** (`Btn_DetailsClose` → `SetBtnDetailsClose`); the variable itself keeps the underscore.
- `MakeSlateChildSize` node pin default SizeRule is already "Fill"; `Layout|HorizontalBoxSlot|SetSize` pins are `(self=slot, InSize)`.
- Enum literal "Visible" is the SetVisibility default so it round-trips omitted — that is expected, not a lost arg.
